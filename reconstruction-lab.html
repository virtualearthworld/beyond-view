This lab runs in your browser. It samples frames from your selected video, detects visual corners, tracks matching image patches, and measures apparent motion between views. The video is processed locally by this page; it is not uploaded.

Observed feature movement

The overlay shows measured image correspondences between two frames. Lines are observations from the video—not guessed objects or a 3D scene. The lab now compares a robust 2D translation model with a robust perspective homography, rejecting tracks that disagree with each model. A homography can explain some perspective changes, but it is not a 3D camera-pose solution.

After analysis, the first sampled frame and tracked feature movements will appear here.

Multi-frame consistency check

This compares each adjacent sampled pair across the clip. It reports feature matches, robust 2D-motion support, and perspective-model support separately. These are useful stability clues, not a calibrated 3D trajectory; no failed pair is filled in with invented motion.

What this milestone proves—and what it does not

  • Implemented here: local frame sampling, corner detection, patch matching, multi-frame feature trajectory linking, and robust 2D motion diagnostics.
  • Next: robust camera-pose estimation, calibrated triangulation, multi-view consistency checks, and conversion of measured points into textured surfaces.
  • Not implemented yet: an end-to-end converter or a walkable 3D reconstruction. This page does not claim otherwise.
